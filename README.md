# International Student Job Data Engineering Platform

## Project Overview

This project focuses on building an end-to-end data engineering pipeline that collects U.S. job postings from multiple APIs.

The main goal is to process and organize job market data to help international students find opportunities based on work authorization, visa sponsorship, and employment requirements.

The project will cover data extraction, inspection, deduplication, transformation, database development, and data warehousing.

## Data Sources

- Headcount
- Greenhouse
- Lever
- Ashby

## Current Progress

The following stages have been implemented:

- **Data Extraction:** Collect job postings from APIs and save the original data as JSON.
- **Data Inspection:** Check job relevance and work authorization information.
- **Deduplication:** Identify duplicate job postings.
- **Availability Verification:** Check whether job postings are still available.
